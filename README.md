# AI Data Pipeline Copilot

## Purpose

AI-powered assistant for investigating data pipeline failures,
identifying likely root causes, finding historical incidents,
analyzing dependencies, and recommending remediation steps.

## Target Users

- Platform Support
- Data Engineers
- Developers
- Engineering Leads

## Core Capabilities

- Pipeline failure investigation
- Root cause analysis
- Historical incident matching
- Dependency analysis
- RAG-based knowledge retrieval
- AI agent investigation
- Evidence-backed recommendations

## Technology

- Python
- Snowflake
- Airflow / Astronomer
- Azure AI Search
- Azure OpenAI
- LangChain
- FastAPI
- Streamlit
- Docker
